# Third-party notices

The project code is MIT OR Apache-2.0. This file records the exact Rust dependency names, versions and SPDX expressions resolved by Cargo.lock. Full upstream notices are retained in `licenses/`; these are legal notices, not project authorship.

The Wasm artifact contains compiled Rust code and standard-library code. The JavaScript loader is generated by wasm-bindgen-cli 0.2.105, whose upstream MIT and Apache-2.0 notices are included under `licenses/wasm-bindgen-0.2.105`. The CLI executable is a build tool and is not shipped. The Rust 1.94.0 notices and the installed toolchain's complete `COPYRIGHT-library.html` inventory are included under `licenses/rust-1.94.0`.

`ts-rs` and `ts-rs-macros` are MIT licensed. They produce the owned protocol declarations; their upstream MIT notices are retained even though the compiler tools are not shipped. `unicode-ident` requires **(MIT OR Apache-2.0) AND Unicode-3.0**; its Unicode notice is included as well as both alternative software licenses. No dependency license is being substituted with the project license.

Normal library dependencies below can contribute compiled code to Rust/Wasm artifacts; link-time elimination varies by target. Procedural macros and build-only dependencies run during compilation. Windows support dependencies are resolved but are not used by the wasm32 or Linux builds. Notices are conservatively included for the entire locked closure.
