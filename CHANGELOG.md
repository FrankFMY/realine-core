# Changelog

## 0.1.0

Initial standalone source and artifact format:

- Rust stream, presence and bounded list state machines with generated TypeScript protocol and
  genuine Wasm bindings.
- Explicit initialization and disposal; injectable transport, presence storage and list providers.
- Stable loaded windows spanning native partitions, with current values, deferred order, retained
  interaction custody, global duplicate checks and failure preflight.
- Local locked build, lint/type/native checks, packed consumers and retained dual-license notices.

is implied by this entry.
